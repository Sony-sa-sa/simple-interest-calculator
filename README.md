# Simple Interest Calculator

## Description
This project is a simple interest calculator implemented as a Bash script. It calculates the simple interest based on user input, using the following input fields:
- **Principal** — the initial amount of money
- **Rate of Interest** — the annual rate of interest (in %)
- **Time Period** — the duration in years

## Formula
Simple Interest = (Principal × Rate of Interest × Time Period) / 100

## Prerequisites
- Bash shell (Linux/macOS/WSL)

## Installation
git clone https://github.com/Sony-sa-sa/simple-interest-calculator.git
cd simple-interest-calculator

## Usage
bash simple-interest.sh

The script will prompt you to enter the principal amount, the rate of interest, and the time period, and it will then compute and display the simple interest.

## Example
Enter the principal amount: 1000
Enter the rate of interest (in %): 5
Enter the time period (in years): 2
Simple Interest: 100.00
