# Simple Interest Calculator

A simple Bash script that calculates simple interest based on user input: principal amount, rate of interest, and time period.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Usage
1. Clone this repository:
   git clone https://github.com/Sony-sa-sa/simple-interest-calculator.git
   cd simple-interest-calculator

2. Run the script:
   bash simple-interest.sh

3. Enter principal, rate of interest, and time period when prompted.

## Example
Enter the principal amount: 1000
Enter the rate of interest (in %): 5
Enter the time period (in years): 2
Simple Interest: 100.00
