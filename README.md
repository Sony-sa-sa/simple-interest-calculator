# Simple Interest Calculator

A simple Bash script that calculates simple interest based on user input.

## Description
This project calculates simple interest using the formula:
Simple Interest = (Principal × Rate × Time) / 100

## Prerequisites
- Bash shell (Linux/macOS/WSL)

## Installation
git clone https://github.com/Sony-sa-sa/simple-interest-calculator.git
cd simple-interest-calculator

## Usage
bash simple-interest.sh

You will be prompted to enter:
- Principal amount
- Rate of interest (%)
- Time period (years)

## Example
Enter the principal amount: 1000
Enter the rate of interest (in %): 5
Enter the time period (in years): 2
Simple Interest: 100.00
